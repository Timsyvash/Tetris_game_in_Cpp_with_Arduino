## ✨ Особливості

- **7 Класичних Тетроміно**: Повна підтримка фігур *I, T, O, J, L, S, Z* із відповідною колірною гамою.
- **Оптимізований рендеринг (Dirty Frame Refresh)**: Кадр перемальовується тільки при зміні стану гри, що виключає затримки зчитування джойстика та мерехтіння світлодіодів.
- **Підтримка Serpentine (Зігзаг) матриць**: Вбудована функція конвертації координат $(X, Y)$ у 1D-індекс для світлодіодних панелей із зігзагоподібним розведенням.
- **Динамічне керування**:
  - Точне переміщення по осі X із програмним приглушенням дребезгу.
  - Обертання фігури по кнопці.
  - **Soft Drop**: Прискорене падіння фігури при відхиленні джойстика вниз.
- **Game Over & Reset**: Анімація програшу з автоматичним перезапуском поля через 2 секунди.

## 🛠 Апаратні вимоги

| Компонент | Кількість | Опис / Примітка |
| :--- | :---: | :--- |
| **Arduino** | 1 | Uno / Nano / Pro Mini або сумісна плата |
| **LED Матриця WS2812B** | 1 | Розмір 16×16 (256 світлодіодів) |
| **Аналоговий джойстик** | 1 | Модуль типу HW-504 (з осьовими потенціометрами та кнопкою) |
| **Блок живлення** | 1 | 5V DC, мінімум **2A–3A** |
| **Конденсатор** *(рекомендовано)* | 1 | 1000uF 6.3V (на лінії живлення 5V) |
| **Резистор** *(рекомендовано)* | 1 | 330Ω–470Ω (на лінії даних `DATA_PIN`) |
