## ✨ Особливості

- **7 Класичних Тетроміно**: Повна підтримка фігур *I, T, O, J, L, S, Z* із відповідною колірною гамою.
- **Оптимізований рендеринг (Dirty Frame Refresh)**: Кадр перемальовується тільки при зміні стану гри, що виключає затримки зчитування джойстика та мерехтіння світлодіодів.
- **Підтримка Serpentine (Зігзаг) матриць**: Вбудована функція конвертації координат $(X, Y)$ у 1D-індекс для світлодіодних панелей із зігзагоподібним розведенням.
- **Динамічне керування**:
  - Точне переміщення по осі X із програмним приглушенням дребезгу.
  - Обертання фігури по кнопці.
  - **Soft Drop**: Прискорене падіння фігури при відхиленні джойстика вниз.
- **Game Over & Reset**: Анімація програшу з автоматичним перезапуском поля через 2 секунди.

## 🛠 Апаратні вимоги

| Компонент | Кількість | Опис / Примітка |
| :--- | :---: | :--- |
| **Arduino** | 1 | Uno / Nano / Pro Mini або сумісна плата |
| **LED Матриця WS2812B** | 1 | Розмір 16×16 (256 світлодіодів) |
| **Аналоговий джойстик** | 1 | Модуль типу HW-504 (з осьовими потенціометрами та кнопкою) |
| **Блок живлення** | 1 | 5V DC, мінімум **2A–3A** |
| **Конденсатор** *(рекомендовано)* | 1 | 1000uF 6.3V (на лінії живлення 5V) |
| **Резистор** *(рекомендовано)* | 1 | 330Ω–470Ω (на лінії даних `DATA_PIN`) |

## 🔌 Схема підключення (Pinout)

### 1. Матриця WS2812B

```text
  [ Блок Живлення 5V ] ─────────────┬─────────────► VCC  (Матриця)
                                   │
  [ Arduino GND ] ─────────────────┼─────────────► GND  (Матриця)
                                   │
  [ Arduino Pin D6 ] ───[ 330Ω ]───┼─────────────► DIN  (Матриця)
                                  ═══ 1000uF
                                   │
                                  GND

🚀 Встановлення та збірка
Варіант A: Arduino IDE
Завантажте та встановіть Arduino IDE.

Встановіть бібліотеку FastLED:

Перейдіть у Скетч -> Включити бібліотеку -> Управління бібліотеками...

Знайдіть FastLED та натисніть Встановити.

Відкрийте файл .ino з кодом гри.

Оберіть вашу плату (Tools -> Board) та відповідний COM-порт.

Натисніть кнопку Завантажити (Upload).

Варіант B: PlatformIO (VS Code)
Створіть новий проект у PlatformIO та додайте у файл platformio.ini:

Ini, TOML
[env:nanoatmega328]
platform = atmelavr
board = nanoatmega328
framework = arduino
lib_deps = 
    fastled/FastLED @ ^3.6.0
🎮 Керування
Plaintext
       ▲ (Обертання / кнопка SW)
       │
◄ ───  ┼  ─── ►  (Рух X: Ліво / Право)
       │
       ▼ (Soft Drop: Прискорене падіння)
Джойстик Вліво / Вправо: Зсув падаючого тетроміно по горизонталі.

Джойстик Вниз: Прискорений спуск фігури.

Натискання на джойстик (SW): Поворот фігури за годинниковою стрілкою на 90°.

⚙️ Конфігурація коду
Основні параметри налаштовуються у заголовку скетчу:

C++
// Налаштування пінів та геометрії
#define DATA_PIN 6         // Цифровий пін даних матриці
#define MATRIX_WIDTH 16    // Ширина сітки (колонки)
#define MATRIX_HEIGHT 16   // Висота сітки (рядки)
#define BRIGHTNESS 20      // Яскравість світлодіодів (0-255)

// Піни органів керування
#define X_PIN A1           // Аналоговий пін осі X
#define Y_PIN A2           // Аналоговий пін осі Y
#define SW_PIN 8           // Пін кнопки обертання

// Таймінги гри (мс)
unsigned long fallInterval = 600;          // Базова швидкість падіння
const unsigned long softDropInterval = 60; // Швидкість при Soft Drop
